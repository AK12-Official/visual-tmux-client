## 非阻断建议及验证边界

pending 仍按 hostId + path 计数。旧连接删除响应在途时，新连接相同路径的保存会暂时拒绝；DOM 实验证实草稿保留，旧请求结束后可恢复。旧 finally 不会清除其他操作的计数。没有证明永久卡死、数据损失或明确规格违背，因此不计入发布阻断。若后续产品要求切换连接后立即并行操作，可统一扩展 pending 的连接范围及其回归测试，不能直接清空计数。

本地工具为 Go1.27.1、Node24.12.0、lint2.13.2。未执行 CI 的 Go1.26.3 或全新 npm ci；四目标仅完成编译，未执行各平台运行验收。SSH/SFTP 自动测试使用 Go 夹具，不代表真实 OpenSSH 兼容验收；完整浏览器端到端、长期负载及崩溃恢复未在本轮实测。上述是证据边界，不是本轮新确认的缺陷。
