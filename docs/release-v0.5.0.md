# Visual Tmux Client v0.5.0

## 更新内容

- 新增 SSH 多主机工作区，可统一添加、探测和管理远程主机，并访问远程 tmux 会话及文件。
- 加强远程连接生命周期、凭据保护、主机状态持久化及并发处理。
- Web 界面支持英语与简体中文，覆盖主机管理、文件编辑、通知和内置帮助，并记住语言选择。
- 改善浏览器存储不可用时的认证与界面行为。

## 升级

备份现有可执行文件及私有状态目录，替换对应平台的二进制并重启应用。保留现有配置、启动参数与凭据。

## 发布准备验证

- 前端类型检查、生产构建及测试通过。
- Go 全量测试与 go vet 通过。
- golangci-lint 配置校验与检查通过。
- 发布包由 scripts/package.sh 生成，包含 macOS/Linux 的 amd64、arm64 构建和 SHA-256 校验和。

正式发布时，将版本提交推送至 main 后，在该提交上创建并推送 v0.5.0 标签；仓库 Release 工作流会构建并发布 GitHub Release。
